# Unfamiliar programs I worked with:
- ESLint is a bug-spotter. It reads your code without running it and flags likely mistakes, such as a variable you never use or a name that doesn’t exist.
- Prettier is an auto-formatter. It rewrites spacing, quotes, and line breaks to one consistent style, so you never argue about style.
- Vitest is a test runner. It calls your functions with known inputs and checks the results match what you expect.
